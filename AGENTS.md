# Agent instructions

This repository documents the Dual Anchor Model, a valuation screen. It is not an application to build or modify unless the user asks for that.

When the user asks to value a company, apply DAM, or sanity-check a growth valuation, read and follow [skills/dual-anchor-model/SKILL.md](skills/dual-anchor-model/SKILL.md). Use cited figures. Do not invent net income, revenue, growth, the discount rate, or market cap.

The note itself is [Dual_Anchor_Model.pdf](Dual_Anchor_Model.pdf). Which growth rate belongs in the formula is [Choosing_the_Growth_Rate.pdf](Choosing_the_Growth_Rate.pdf). A short index for agents that arrive without this file is [llms.txt](llms.txt).
